t-notes guide

Notes

Hit + New note: first line is the Title, then write the body — select text for bold, italic, color, and size. Save, and it appears as a titled note. Click a #tag to filter by it. The label icon opens the color palette. Archive with the box icon; restore from show archived.

Board

Cards live in color-coded lists (Jira-style accent per column) — add, rename, or delete lists freely. + New card opens the same title-first popup. Drag cards between lists or use the arrow buttons. Tick the checkbox to mark done. Colored strips on a card are its labels.

Card detail

Click the grid icon on any card: description, checklist with progress bar, due date (overdue turns red), comments, labels. Paste multiple lines into the checklist field to add them in bulk.

Find things

Search box, color dots, and #tags all combine as filters. The row under the header shows what is active — clear resets.

Your data

Everything lives in this browser only (localStorage). Use the download button for a JSON backup and the upload button to restore it.

Desktop

The power button toggles launch-on-login (Windows builds). The moon/sun button switches theme.
