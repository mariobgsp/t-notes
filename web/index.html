t-notes guide

Notes

Hit + New note: first line is the Title, then write the body — select text for bold, italic, color, and size. Save, and it appears as a titled note. Click a note (or the ✎ icon) to edit it in the popup. The ✎ icon reopens it; click the note's body opens a detail dialog with a checklist + progress (add items, tick them off) just like cards. Click a #tag to filter. The label icon opens the color palette. Archive with the box icon; restore from show archived.

Board

Cards live in color-coded lists (Jira-style accent per column) — add a list with the New list… box at the bottom, rename (✎) or delete (×) freely. + New card opens the title-first popup with a List picker (which column it lands in). Drag cards between lists or use the arrow buttons. Tick the checkbox to mark done. Colored strips on a card are its labels.

Card detail

Click the grid icon on any card: description, checklist with progress bar, due date (overdue turns red), comments, labels. Paste multiple lines into the checklist field to add them in bulk.

Find things

Search box, color dots, and #tags all combine as filters. The row under the header shows what is active — clear resets.

Your data

Everything lives in this browser only (localStorage). Use the download button for a JSON backup and the upload button to restore it.

AI assistant

Hit the sparkle button: pick Command Code (default, model muse-spark-1.3-contributor), paste your key, Test, Save. Then use Summarize, Checklist, Improve, Ideas inside new notes and card details. Key stays in this browser and is never exported.

Desktop

The power button toggles launch-on-login (Windows builds). The moon/sun button switches theme.
